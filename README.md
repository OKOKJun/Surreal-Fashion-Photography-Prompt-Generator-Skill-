# 先锋时尚创意摄影策划 Skill (Creative Fashion Photography)

本项目是一个专为 AI 时尚摄影、商业视觉策划与先锋视觉大片打造的可复用 Agent Skill。系统结合用户提供的**模特资产**与**场景资产**，自动化完成视觉基因解构、光学布光规划、9 镜头叙事分镜搭建，并生成适配 **Nano Bananan Pro** 与 **Nano Bananan 2.1** 的高保真中文生图提示词。

---

## 🌟 核心特性

- **反平庸人像美学**：坚决摒弃千篇一律的大光圈糖水虚化、磨皮柔焦与居中呆板站姿，强制锁定深景深（f/8–f/11）与高对比度机顶硬直闪光质感。
- **语境冲突建构**：将高级时装剪裁（如解构礼服、粗纺大衣）与实用主义粗粝空间（工业桥洞、运动竞技场、街头车流）进行符号错配，制造强烈视觉张力。
- **动态 9 镜头叙事分镜**：依照「侵入—对峙—窥视—微观—拉伸—沉浸—交锋—抽离—定格」的叙事弧线，构建完整的时尚故事组图。
- **专为 Nano Bananan 优化**：单段中文生图提示词均在 200 字以上，融合透视参数、光影轨迹、面料纤维与原生肤质细节，高度适配现代大模型解析特性。

## 🎬 9 镜头连续性叙事结构

每次生成的方案均完整覆盖以下 9 个分镜节奏：

1. **Shot 1【侵入】**：远景/环境大全景 —— 主体作为异质色彩符号介入宏大场景。
2. **Shot 2【对峙】**：全身景 —— 人物服装轮廓与场景建筑线条形成体量抗衡。
3. **Shot 3【窥视】**：画中画中景 —— 通过立柱、球拍、后视镜等实体道具框取局部。
4. **Shot 4【微观】**：微距特写 —— 领口、配饰、毛呢纤维与真实皮肤毛孔微观质感。
5. **Shot 5【拉伸】**：动态超广角特写 —— 贴地 15–20cm 仰拍，极端拉伸前伸鞋底与裤脚。
6. **Shot 6【沉浸】**：半身环境互动 —— 主体倚靠/融入粗糙环境肌理，冷酷情绪凝固。
7. **Shot 7【交锋】**：正面行进中景 —— 大步跨越动作抓拍，扬起衣摆与直视镜头的锋芒。
8. **Shot 8【抽离】**：纵深背影远景 —— 主体背向镜头步入空间深处，孤独而决绝。
9. **Shot 9【定格】**：中心对称主视觉 —— 极具秩序感与仪式感的封面级压轴画报。

## 🛠️ 安装与使用指南

### 在支持 Agent Skills 的平台中使用
1. 将 `SKILL.md` 文件放置在你的技能目录或 Agent 的 Skill 库中。
2. 在对话中上传或描述你的**模特图片**与**场景图片**。
3. 发送触发指令：
   > “分析我的模特和场景，按时尚创意摄影技能生成一组 9 镜头叙事大片方案。”
4. 系统将根据场景自动适配（或提供流派选择题），并输出完整光学执行单与 9 段 200+ 字中文生图提示词。
